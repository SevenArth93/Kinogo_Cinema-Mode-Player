## Описание 
Скрипт для сайта https://kinogo.luxury

Выводит плеер сайта на верх и по всей ширине окна браузера

Возможность автовоспроизведения видео, вкл/выкл

Сворачивание плеера, чтобы ознакомится с информация на странице сайта

## Установка 

1. Установите расширение для запуска пользовательских скриптов:

    - [Tampermonkey](https://www.tampermonkey.net/)
    
2. [Разрешите выполнение userscript’ов и режим разработчика](https://www.tampermonkey.net/faq.php?locale=ru#Q209) в вашем браузере.
3. Установите скрипт, перейдя по [этой ссылке](https://github.com/SevenArth93/Kinogo_Cinema-Mode-Player/raw/refs/heads/main/Kinogo_Luxury_Cinema_Mode_Player.user.js).
<br>_(либо скачайте `Kinogo_Luxury_Cinema_Mode_Player.user.js`, нажав на файл, а там кнопку RAW, тогда Tampermonkey подхватит установку)_

<p>Проверялась работа скрипта на браузерах Яндекс и Brave</p>
